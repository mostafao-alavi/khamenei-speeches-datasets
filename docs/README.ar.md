# 🇸🇦 مجموعات البيانات المعالجة لخطابات السيد علي الخامنئي لتطبيقات الذكاء الاصطناعي
### ملفات Parquet و JSONL وقاعدة بيانات SQLite FTS5 للبحث الدلالي ونظم RAG

---

## 📖 نبذة عن المستودع
تم تصميم هذا المستودع وتجهيزه لخدمة مهندسي الذكاء الاصطناعي وباحثي معالجة اللغات الطبيعية (NLP). يضم المستودع 1,066 خطاباً كاملاً تم تدقيقها وتجميعها في صيغ رقمية قياسية فائقة السرعة، تتيح الاستعلام السريع والتدريب المباشر لنماذج اللغة وتغذية قواعد البيانات المتجهة (Vector Databases).

---

## 📦 التنسيقات المتوفرة
1. **ملف Parquet العمودي (`exports/khamenei_speeches_corpus.parquet`):**
   - الحجم: 13.6 ميجابايت مع ضغط Snappy.
   - مخصص للتحليلات الإحصائية والاستعلامات الضخمة السريعة عبر Pandas و DuckDB.
2. **ملف JSONL المتدفق (`exports/khamenei_speeches_corpus.jsonl`):**
   - الحجم: 30.2 ميجابايت.
   - الصيغة المثالية لتدريب نماذج الذكاء الاصطناعي (Fine-Tuning) وبناء خطوط أنابيب RAG.
3. **قاعدة بيانات SQLite FTS5 (`database/speeches_fts.db`):**
   - محرك بحث متكامل بالنص الكامل يدعم الحروف العربية والفارسية بدقة فائقة.
