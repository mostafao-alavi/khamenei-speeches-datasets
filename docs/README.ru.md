# 🇷🇺 Обработанные Датасеты Выступлений Аятоллы Хаменеи для ИИ и Анализа Данных
### Высокопроизводительные Форматы Parquet, JSONL и База Данных SQLite FTS5 для RAG и LLM

---

## 📌 Обзор
Этот репозиторий содержит структурированные наборы данных для исследователей в области обработки естественного языка (NLP) и инженеров по машинному обучению, предназначенные для построения поисковых RAG-систем и дообучения языковых моделей.

---

## 📦 Доступные Форматы
1. **Колоночный формат Parquet (`exports/khamenei_speeches_corpus.parquet`):** 13,6 МБ, сверхбыстрое чтение через Pandas, Polars и DuckDB.
2. **JSON Lines (`exports/khamenei_speeches_corpus.jsonl`):** 30,2 МБ, потоковый формат для Hugging Face и векторных баз данных.
3. **SQLite FTS5 (`database/speeches_fts.db`):** Встроенный полнотекстовый поиск по 3,15 млн слов.
