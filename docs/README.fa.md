# 🇮🇷 مجموعه‌داده‌های پردازش‌شده بیانات آیت‌الله خامنه‌ای ویژه هوش مصنوعی و RAG
### فایل‌های بهینه‌سازی‌شده Parquet ،JSONL و پایگاه داده SQLite مجهز به جستجوی FTS5

---

## 🎯 معرفی و هدف این مخزن
این مخزن اختصاصاً جهت پاسخگویی به نیازهای پیشرفته جامعه هوش مصنوعی، تحلیل‌گران کلان‌داده، و توسعه‌دهندگان خط‌لوله‌های RAG (Retrieval-Augmented Generation) طراحی و استانداردسازی شده است. تمامی ۱,۰۶۶ سخنرانی پالایش‌شده و اصیل، تجمیع شده و در فرمت‌های مدرن تحلیلی با فشرده‌سازی حداکثری و سرعت بارگذاری میلی‌ثانیه‌ای در دسترس قرار دارند.

---

## 📦 فرمت‌های ارائه‌شده و مشخصات فنی

### ۱. فایل پرسرعت و ستونی Parquet (`exports/khamenei_speeches_corpus.parquet`)
- **اندازه فایل:** حدود ۱۳.۶ مگابایت (فشرده‌شده با الگوریتم Snappy)
- **مزیت:** خواندن ستونی فوق‌سریع بدون نیاز به لود کل متن در حافظه RAM؛ بسیار ایده‌آل برای تحلیل‌های آماری، نمودار روند تاریخی کلمات، کتابخانه‌های Polars، Pandas، DuckDB و PySpark.

### ۲. فایل خط‌به‌خط استاندارد JSONL (`exports/khamenei_speeches_corpus.jsonl`)
- **اندازه فایل:** حدود ۳۰.۲ مگابایت (Plaintext UTF-8)
- **مزیت:** استاندارد اصلی برای آموزش مدل‌ها (Fine-Tuning)، بارگذاری در فریمورک‌های LangChain، LlamaIndex، و استریم خطی داده‌ها در وکتور دیتابیس‌ها بدون سربار حافظه.

### ۳. پایگاه داده SQLite با موتور جستجوی تمام‌متن FTS5 (`database/speeches_fts.db`)
- **فناوری:** SQLite 3 همراه با جدول مجازی `speeches_fts` با استفاده از توکنایزر یونیکد (`tokenize='unicode61'`).
- **مزیت:** قابلیت جستجوی متنی فوق‌سریع در میان ۳.۱۵ میلیون کلمه در کسری از ثانیه همراه با خروجی هایلایت‌شده (Snippets).

## 📊 اسکیما و ساختار فیلدهای داده (Schema)
| نام ستون | نوع داده | توضیحات |
| :--- | :--- | :--- |
| `id` | Integer | شناسه رسمی و یکتای بیانات در منبع اصلی |
| `year` | Integer | سال هجری شمسی ایراد سخنرانی (۱۳۵۷ تا ۱۴۰۴) |
| `solar_date` | Text | تاریخ کامل شمسی به فرمت استاندارد `YYYY/MM/DD` |
| `title` | Text | عنوان رسمی و کامل ثبت‌شده برای سخنرانی |
| `url` | Text | پیوند مستقیم به صفحه متن اصلی در درگاه رسمی |
| `has_pdf` | Integer | مقدار بولین (0 یا 1) نشان‌دهنده وجود سند PDF رسمی |
| `word_count` | Integer | تعداد دقیق کلمات متن کامل بیانات |
| `char_count` | Integer | تعداد دقیق نویسه‌ها (کاراکترها) متن |
| `content` | Text | متن کامل، پاکسازی‌شده و بدون تحریف سخنرانی |
